# BC HLTH 5328 source template

`bc_5328_original.pdf` is an unmodified local copy of the user-selected public blank form:
https://www2.gov.bc.ca/assets/gov/health/forms/5328fil.pdf

Retrieved 2026-10-30. Printed revision: HLTH 5328 Rev. 2019/09/30.
The app uses its actual AcroForm fields, not a recreated layout. No real eligibility
criteria or submission mechanism is implemented. The original is preserved; draft
exports receive a synthetic demo label and a separate evidence/review appendix.

This template is a user-selected demonstration target. Its availability does not
establish that it is the current or appropriate form for any particular drug.
